DISCUSSION SLIDES
=================

Put your discussion slides here. The server auto-detects any image files in
this folder and shows them on the TV "DISCUSSION" page in order.

Name them so they sort correctly, e.g.:

    slide1.jpg
    slide2.jpg
    slide3.png
    ...

Supported formats: .jpg .jpeg .png .webp .gif
Recommended size: 1920x1080 px

The left/right arrows on the controller (PREV SLIDE / NEXT SLIDE) navigate
through them. The slide counter on the TV shows "current / total".
